## Verificación realizada

- 85 pruebas JS y 43 pruebas Python (suite automatizada). Prueba estática dedicada a polido UI.
- Comparación visual con fixtures DOM en Chromium para 375, 390, 430, 768, 1024 y 1440 CSS px, sin overflow horizontal; modo oscuro en navegación/vacío.
- Medición de alineación principal/inferior a 1440px: diferencia 13px → 0px. A 768px: diferencia 9px → 2px en fixture (inspección final de SVG pendiente en Safari real).
- Los fixtures son representaciones de clases/markup de Percí; **no** constituyen navegación E2E autenticada real ni garantía de apariencia exacta en Safari iPhone.

## Deuda UX para futuras fases

- Modal: manejo de foco (trap y retorno al disparador) necesita auditoría de accesibilidad con teclado y VoiceOver.
- Estilos originales de prototipo mantienen reglas históricas superpuestas; consolidar por componentes cuando se realice rediseño de arquitectura CSS.
- Considerar reducir dependencia visual de fotos remotas para uso completamente offline.

**Sin cambios** a endpoints, políticas RLS, estados de autenticación, lógica de sync, conciliación offline, entrenamientos ni datos de usuarios.
